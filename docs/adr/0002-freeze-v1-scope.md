# ADR-0002：冻结 V1 范围与验收基线

- 状态：Accepted
- 日期：2026-09-02
- 基线标识：`v1-scope-2026-09-02`

## 决策

V1 范围以 `docs/02-project-goals.md`、`docs/05-roadmap.md` 和 `docs/06-acceptance-tests.md` 当前版本为准。

- 故障族固定为延迟、错误率、数据库、资源、网络、配置、发布和容量八类。
- 正式验收集不少于 30 个用例。
- P0 指标固定为调查完成率、Top-1/Top-3 命中率、有效证据引用率、无依据陈述率、只读工具成功率、安全阻断率、幂等阻断率、检查点恢复率、调查 P95 和 Trace 完整率。
- V1 不连接真实生产环境，不开放无人审批变更，不引入 Kafka、Temporal、独立搜索集群或多 Agent 集群。

任何降低安全门禁、减少故障族或改变指标分母的修改都必须新增 ADR，不得只修改实现或评测脚本。

## 后果

后续阶段可以改进模型、Prompt、检索和工具实现，但必须在同一冻结数据定义下比较。新增能力若不能改善上述验收指标，不作为 P0 架构复杂度的理由。
